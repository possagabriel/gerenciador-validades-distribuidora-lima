# Material de replicação do TCC

O [pacote de replicação](pacote_replicacao_tcc.zip) reúne o backend e o
painel da revisão `11a9e089309e3f6fc90160694ba88c525fe69d4c`, os dados
sintéticos usados no caso demonstrativo e os scripts de preparação e
verificação. O arquivo `README.md` dentro do ZIP descreve a instalação e
os resultados esperados. `origem.json` registra a revisão e os hashes dos
arquivos originais.

O aplicativo móvel foi desenvolvido por Gabriel Possa Lima. O backend,
a API e o painel foram desenvolvidos por Darlan José dos Santos.

O código original incluído no pacote é distribuído sob a [licença MIT](../LICENSE).
Uma cópia da licença acompanha o ZIP.

Na conferência de 19/11/2026, passaram os 99 testes do backend. O roteiro
também confirmou o lote crítico, a associação do código ao suco, a
sugestão de R$ 9,38, a saída de 20 para 17 unidades e o total de R$ 35,00
do lote vencido. A saída foi revertida ao terminar a verificação.
